# **Loop Continued**

## **Exercise 1 — User Controls the Loop**

Ask the user to enter an integer.

Use the user's number to determine how many times the `for` loop runs.

Print `"Hello"` each time the loop runs.

### Example Input

```text
5
```

### Expected Output

```text
Hello
Hello
Hello
Hello
Hello
```

## **Exercise 5 — Check if a Word Is Symmetric**

Write a Java program that asks the user to enter a word.

Use a `for` loop to check whether the word is **symmetric** (the same when read from left to right and right to left).

If the word is symmetric, print:

```text
Symmetric
```

Otherwise, print:

```text
Not symmetric
```

### Example 1

**Input:**

```text
level
```

**Output:**

```text
Symmetric
```

### Example 2

**Input:**

```text
hello
```

**Output:**

```text
Not symmetric
```
## **Exercise 6 — Check Increasing Order**

Write a Java program that asks the user to enter a word.

The word must contain **lowercase letters only**.

Use a `for` loop to:

1. Check whether the word contains only lowercase letters.
2. If the word contains an uppercase letter, print:
   ```text
   Invalid
   ```
3. If the word contains only lowercase letters, check whether the characters are in **increasing alphabetical order**.
4. If the characters are in increasing order, print:
   ```text
   Increasing order
   ```
5. Otherwise, print:
   ```text
   Not increasing order
   ```

### Example 1

**Input:**
```text
abcde
```

**Output:**
```text
Increasing order
```

### Example 2

**Input:**
```text
acbde
```

**Output:**
```text
Not increasing order
```

### Example 3

**Input:**
```text
Abcde
```

**Output:**
```text
Invalid
```

### Example 4

**Input:**
```text
Hello
```

**Output:**
```text
Invalid
```
