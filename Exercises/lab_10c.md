# Map
---

## 1. Character Frequency in a String
Write a program to count the frequency of each character in a given string using a `HashMap`.

**Example:**
- Input: `"apple"`
- Output: `{a=1, p=2, l=1, e=1}`

---

## 2. Word Frequency Counter
Write a program to count how many times each word appears in a sentence.

**Example:**
- Input: `"java is easy java"`
- Output: `{java=2, is=1, easy=1}`

---

## 3. Count Vowels in a String
Write a program to count the frequency of vowels (`a, e, i, o, u`) using a map.

**Example:**
- Input: `"education"`
- Output: `{a=1, e=1, i=1, o=1, u=1}`

---

## 4. Find Most Frequent Character
Write a program to find the character that appears the most in a string using a map.

**Example:**
- Input: `"success"`
- Output: `Most frequent character: s`

---

## 5. First Non-Repeating Character
Write a program to find the first character in a string that does not repeat using a map.

**Example:**
- Input: `"swiss"`
- Output: `First non-repeating character: w`

---

## 6. Count Digits in a String
Write a program to count how many times each digit appears in a string using a map.

**Example:**
- Input: `"a1b2a1"`
- Output: `{1=2, 2=1}`

---

## 💡 Note
- Use `HashMap<Character, Integer>` for character problems  
- Use `HashMap<String, Integer>` for word problems  
- Use `Character.isDigit(ch)` for checking if char is digit.
